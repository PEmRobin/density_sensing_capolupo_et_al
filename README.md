Code archive for Capolupo et al, "Tissue swelling and local mechanosensation drive crypt convergence in intestinal development."

Contains both vertex models and organoid models of intestinal crypt morphogenesis. The four example codes included implement:
- budding of a crypt as function of villus swelling
- crypt asymmetry as function of swelling and myosin variability
- snapshots of organoids under different conditions,
- morphogenetic timecourses of organoids with two crypts.

All details (including parameter values for the different conditions) are provided within each code as well as in the paper's Supplementary Information.
